# Atoms

Componentes atómicos Kreo vendored en `apps/web`.

| Componente | Notas |
|------------|-------|
| Button | `tactile`, `brand`, `action-*`, `asChild`, link con underline draw |
| InputText | `floatingLabel`, shake en error |
| Select | `options` planas o `optionGroups` con `<optgroup>` nativo |
| Loader | `variant`: spinner \| orb \| skeleton |
| Skeleton | `animation`: pulse \| shimmer |
| thinking-orb/ | Wrapper de `thinking-orbs` — 9 estados IA |

Import: `@/components/atoms/{Name}`
