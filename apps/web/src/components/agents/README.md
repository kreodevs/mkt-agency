# Agentes (UI)

- `BrandInterviewHistory.tsx` — listado de entrevistas Brand Analyst con enlace al resultado.
- `BrandProductOnboardingPanel.tsx` — inferencia desde URL + tags inline en Brand Analyst (sin ir al wizard).
- `CompetitorAnalysisReport.tsx` — reporte de análisis competitivo: panorama, **tu posición**, ventajas competitivas, comparativa directa, competidores, oportunidades e insights.
- `CompetitorIntelHistory.tsx` — historial de análisis competitivos.
- Usado en las páginas hub de cada agente (`/agents/*`).
