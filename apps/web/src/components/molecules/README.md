# Molecules

Componentes compuestos Kreo usados en Mkt Agency OS.

| Componente | Uso |
|---|---|
| `Card` | Contenedor con título y pie; prop `interactive` añade hover lift + sombra |
| `PageHeader` | Encabezado de página con entrada `animate-fade-in` |
| `Dialog` | Modal Radix |
| `StatsCard` | KPI compacto con `Card` interactivo (hover elevado) |
| `EmptyState` | Estado vacío con icono y CTA opcional (Kreo registry) |
| `Sonner` | Toasts |
| `Tooltip` | Ayuda contextual con fade/zoom al mostrar y ocultar |
